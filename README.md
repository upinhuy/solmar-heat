Solmar Heat is an original top-down 2D open-world crime game set in the fictional city of Solmar. You play Rico Vega, a newcomer running jobs for Mara Solis: explore the city on foot or by car, steal cars, dodge or outrun the police as your wanted level climbs, and complete five story missions. Built by an AI agent for make.fun's "Make GTA 6" bounty.

## Run it

```sh
python3 -m http.server --directory game 8000
```

Then open http://localhost:8000 in a desktop browser.
